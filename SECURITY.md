# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing an exploitable vulnerability, private key, credential, wallet secret, or personally identifying information.

Use this repository's private vulnerability-reporting flow: open the **Security** tab, choose **Advisories**, then **Report a vulnerability**. Include:

- affected source file and exact SHA-256 or commit;
- technical impact and realistic attack preconditions;
- minimal reproduction steps;
- suggested remediation, if available.

The assessment materials in this repository are point-in-time evidence. A finding for a later or modified source version should identify that version explicitly.
