# Published evidence

This directory contains the point-in-time test summary, coverage summary, Slither summary, and path-sanitized raw coverage/Slither JSON used by the AEGENT-authored assessment.

Machine-specific absolute paths were replaced with stable `review-workspace/` labels before publication. Detector records, counters, source mappings, and coverage measurements were not otherwise changed. The summary files bind the local raw and public sanitized artifacts by SHA-256.
